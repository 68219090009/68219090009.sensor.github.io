ทำความรู้จักกับ KY-032 โมดูลเซ็นเซอร์อินฟราเรดสำหรับตรวจจับสิ่งกีดขวางระยะสั้น เหมาะสำหรับผู้เริ่มต้นใช้งาน Arduino, ESP32 และงานระบบอัตโนมัติ

ความรู้เบื้องต้นเกี่ยวกับเซ็นเซอร์

เซ็นเซอร์คืออุปกรณ์ที่รับข้อมูลจากสิ่งแวดล้อม แล้วแปลงเป็นสัญญาณไฟฟ้าที่ไมโครคอนโทรลเลอร์สามารถประมวลผลได้ โดยทั่วไปมี 3 ขั้นตอน ได้แก่ ตรวจจับสภาวะ แปลงข้อมูลเป็นสัญญาณ และส่งต่อให้ระบบควบคุมวิเคราะห์

ประเภทเอาต์พุต

  • Analog Output: ส่งค่าแบบต่อเนื่องตามค่าที่วัดได้
  • Digital Output: ส่งสถานะ 0/1 หรือ HIGH/LOW
  • สัญญาณพิเศษ: เช่น I2C, SPI และ UART สำหรับข้อมูลที่ละเอียดขึ้น

ลักษณะสำคัญ

ความละเอียด ความแม่นยำ ความไว และเวลาในการตอบสนอง ล้วนเป็นคุณสมบัติที่ควรพิจารณาเมื่อนำเซ็นเซอร์ไปใช้งาน

ข้อมูลเซ็นเซอร์ KY-032

โมดูล KY-032 ใช้หลอดส่งอินฟราเรด (IR LED) และตัวรับอินฟราเรด โดยมี IC LM393 ทำหน้าที่เปรียบเทียบสัญญาณ เมื่อตรวจพบแสงสะท้อนจากวัตถุ เอาต์พุตจะเปลี่ยนเป็น LOW (0) และไฟแสดงผลบนโมดูลจะติด

แรงดันไฟฟ้า3.3V ถึง 5V DC
ระยะตรวจจับประมาณ 2 ถึง 40 เซนติเมตร
เอาต์พุตDigital: HIGH / LOW

ขาต่อและฟังก์ชัน

4ENHIGH เพื่อเปิดใช้ หรือ LOW เพื่อปิดใช้งาน

ตัวอย่างโค้ด Arduino

const int obstaclePin = 2;
const int ledPin = 13;

void setup() {
  pinMode(obstaclePin, INPUT);
  pinMode(ledPin, OUTPUT);
  Serial.begin(9600);
}

void loop() {
  int obstacleState = digitalRead(obstaclePin);

  if (obstacleState == LOW) {
    digitalWrite(ledPin, HIGH);
    Serial.println("พบสิ่งกีดขวาง");
  } else {
    digitalWrite(ledPin, LOW);
    Serial.println("เส้นทางว่าง");
  }
  delay(100);
}

ข้อสังเกตและสรุป

  • แสงแดดจัดหรือแสงอินฟราเรดจากแหล่งอื่นอาจรบกวนการทำงาน
  • วัตถุสีขาวหรือผิวเรียบสะท้อนอินฟราเรดได้ดีกว่าวัตถุสีดำหรือผิวขรุขระ
  • ควรตั้งความถี่ของ R6 ไว้ใกล้ 38kHz และใช้ R5 ปรับระยะตรวจจับ
  • เหมาะกับการตรวจจับแบบพบ/ไม่พบ ไม่เหมาะกับการวัดระยะเชิงตัวเลขที่แม่นยำ

สรุป: KY-032 ใช้งานง่าย ประหยัด และตอบสนองรวดเร็ว เหมาะกับหุ่นยนต์หลบสิ่งกีดขวาง ระบบนับชิ้นงาน และโครงงานอัตโนมัติเบื้องต้น
