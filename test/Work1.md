

# ออกแบบวิธีการทดสอบ KY-032 Sensor เพื่อแสดงผลที่ Serial Monitor

## 1. วัตถุประสงค์

การทดสอบเซ็นเซอร์ KY-032 มีวัตถุประสงค์เพื่อยืนยันว่าการตรวจจับสิ่งกีดขวางระยะสั้นด้วยคลื่นอินฟราเรด (IR) สามารถอ่านค่าสถานะทางดิจิทัลได้ถูกต้อง และแสดงผลการตรวจจับผ่าน Serial Monitor อย่างชัดเจน เพื่อใช้ประเมินระยะและประสิทธิภาพก่อนนำไปประกอบเข้ากับตัวหุ่นยนต์หรือระบบควบคุมอัตโนมัติ

---

## 2. อุปกรณ์ที่ใช้

* **ไมโครคอนโทรลเลอร์:** Arduino Uno (หรือ ESP32)
* **เซ็นเซอร์:** โมดูล KY-032 IR Obstacle Avoidance Sensor
* **สายสัญญาณ:** สายไฟ Jumper (Female to Male)
* **เครื่องมือซอฟต์แวร์:** คอมพิวเตอร์ที่ติดตั้ง Arduino IDE หรือ PlatformIO
* **เครื่องมือแสดงผล:** Serial Monitor (ความเร็ว Baud Rate 9600)
* **แผ่นวัตถุสำหรับทดสอบ:** กระดาษสีขาว หรือวัตถุผิวเรียบ

## 3. หลักการทดสอบ

1. ต่อสายไฟจ่ายพลังงานและเชื่อมขาเอาต์พุตดิจิทัล (OUT) เข้ากับไมโครคอนโทรลเลอร์
2. ตั้งค่าขา GPIO เป็นโหมดรับข้อมูลดิจิทัล (`INPUT`)
3. ใช้คำสั่ง `digitalRead()` อ่านสถานะของขาเซ็นเซอร์ในวงรอบเวลาที่กำหนด
4. แปลงสถานะทางไฟฟ้าเพื่อส่งข้อความแสดงสถานะผ่านทาง Serial Monitor (Baud Rate: 9600)
5. นำวัตถุมาบังด้านหน้าเซ็นเซอร์เพื่อทดสอบการตอบสนอง และปรับแต่งระยะการตรวจจับด้วย Trim Potentiometer (R5) บนบอร์ด

## 4. ขั้นตอนการออกแบบ

### 4.1 การต่อวงจร

การต่อขารับ-ส่งสัญญาณระหว่าง Arduino Uno และ KY-032:

| ขาบน KY-032 | ขาบน Arduino Uno | คำอธิบาย |
| --- | --- | --- |
| **GND** | GND | ขั้วลบ / กราวด์ร่วม |
| **+5V / VCC** | 5V | ขั้วบวกจ่ายไฟเลี้ยง (3.3V - 5V) |
| **OUT** | D2 | ขาอ่านสัญญาณดิจิทัล (Digital Input) |
| **EN** | *(ไม่จำเป็นต้องต่อ)* | ขาควบคุมเปิด/ปิดการส่ง IR (มี Jumper ต่อ Pull-up ไว้อยู่แล้ว) |

### 4.2 การเขียนโปรแกรม

โปรแกรมทำงานโดยอ่านค่าดิจิทัลจากขา D2:

* **เมื่อพบสิ่งกีดขวาง (Obstacle Detected):** เซ็นเซอร์ส่งค่า **LOW (0)**
* **เมื่อไม่พบสิ่งกีดขวาง (Path Clear):** เซ็นเซอร์ส่งค่า **HIGH (1)**

### 4.3 ตัวอย่างโค้ด

```cpp
const int sensorPin = 2; // ขา D2 เชื่อมต่อกับ OUT ของ KY-032

void setup() {
  Serial.begin(9600);           // เริ่มต้น Serial Communication
  pinMode(sensorPin, INPUT);     // กำหนดให้ขา D2 เป็น Digital Input
  Serial.println("--- KY-032 Sensor Test Initialized ---");
}

void loop() {
  int sensorState = digitalRead(sensorPin); // อ่านสถานะจากเซ็นเซอร์ (HIGH หรือ LOW)

  Serial.print("Raw Signal: ");
  Serial.print(sensorState);
  
  if (sensorState == LOW) {
    Serial.println(" | Status: [ OBSTACLE DETECTED! ]");
  } else {
    Serial.println(" | Status: Clear");
  }

  delay(300); // หน่วงเวลา 300ms เพื่อให้อ่านผลบน Serial Monitor ได้สบายตา
}

```

## 5. วิธีการวิเคราะห์ผลลัพธ์

* **กรณีปกติ:** เมื่อไม่มีวัตถุอยู่ด้านหน้า ไฟ LED บนโมดูลจะดับ สัญญาณบน Serial Monitor จะขึ้นค่า `Raw Signal: 1 | Status: Clear`
* **กรณีพบสิ่งกีดขวาง:** เมื่อนำวัตถุมาวางกั้นในระยะ 2–40 ซม. ไฟ LED แสดงผลบนโมดูลจะติดสว่าง และข้อความจะเปลี่ยนเป็น `Raw Signal: 0 | Status: [ OBSTACLE DETECTED! ]`
* **การแก้ไขปัญหา (Troubleshooting):**
* หากข้อความค้างอยู่ที่ `OBSTACLE DETECTED!` ตลอดเวลา ให้ใช้ไขควงหมุนปรับ Potentiometer (R5) ทวนเข็มนาฬิกาเพื่อลดความไวลง
* ตรวจสอบว่าแผ่น Jumper บนขา EN เสียบเชื่อมวงจรไว้อยู่



## 6. ตัวอย่างผลลัพธ์ที่ควรเห็นใน Serial Monitor

```text

Raw Signal: 1 | Status: Clear
Raw Signal: 1 | Status: Clear
Raw Signal: 0 | Status: [ OBSTACLE DETECTED! ]
Raw Signal: 0 | Status: [ OBSTACLE DETECTED! ]
Raw Signal: 1 | Status: Clear

```

## 7. สรุป

การทดสอบเซ็นเซอร์ KY-032 ผ่าน Serial Monitor ช่วยยืนยันว่าวงจรส่ง-รับแสงอินฟราเรดทำงานปกติ และไมโครคอนโทรลเลอร์สามารถรับรู้การมีอยู่ของสิ่งกีดขวางได้อย่างแม่นยำ สัญญาณเอาต์พุตแบบดิจิทัลที่ได้นี้สามารถนำไปเขียนเงื่อนไขควบคุมมอเตอร์เพื่อสร้างหุ่นยนต์หลบสิ่งกีดขวาง หรือประยุกต์ใช้ในระบบนับชิ้นงานบนสายพานอัตโนมัติได้อย่างมีประสิทธิภาพ
