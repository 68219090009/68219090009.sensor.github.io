# KY-032 Obstacle Avoidance Sensor Module

ข้อมูลสรุปของโมดูลเซ็นเซอร์ตรวจจับสิ่งกีดขวาง KY-032 สำหรับใช้งานกับ Arduino, ESP32 และ PlatformIO

## 1. ความรู้เบื้องต้นเกี่ยวกับเซ็นเซอร์ (Sensor Fundamentals)

เซ็นเซอร์ (sensor) คืออุปกรณ์ที่ใช้รับข้อมูลจากสิ่งแวดล้อมและแปลงข้อมูลนั้นให้เป็นสัญญาณไฟฟ้าที่เครื่องอิเล็กทรอนิกส์สามารถประมวลผลได้ เซ็นเซอร์มักถูกใช้ในระบบอัตโนมัติและโครงงานอิเล็กทรอนิกส์เพื่อให้เครื่องจักรหรือไมโครคอนโทรลเลอร์สามารถรับรู้โลกรอบตัวได้

### หลักการทำงานของเซ็นเซอร์

โดยทั่วไปเซ็นเซอร์จะทำงานผ่าน 3 ขั้นตอนหลัก

1. ตรวจจับสภาวะหรือสิ่งแวดล้อม เช่น แสง อุณหภูมิ ความดัน ความชื้น หรือระยะห่างวัตถุ
2. แปลงข้อมูลเป็นสัญญาณไฟฟ้า เช่น แรงดัน กระแส หรือข้อมูลดิจิทัล
3. ส่งสัญญาณให้กับไมโครคอนโทรลเลอร์หรืออุปกรณ์ประมวลผลเพื่อวิเคราะห์ต่อ

### ประเภทของเอาต์พุตจากเซ็นเซอร์

* **Analog Output:** ส่งค่าที่เปลี่ยนแปลงต่อเนื่องตามค่าที่วัดได้
* **Digital Output:** ส่งค่าเป็น 0/1 หรือ High/Low เพื่อบอกสถานะการตรวจพบวัตถุ
* **ข้อมูลเชิงสัญญาณพิเศษ:** เช่น I2C, SPI, UART สำหรับระบบที่ต้องการข้อมูลละเอียดมากขึ้น

### ลักษณะสำคัญของเซ็นเซอร์

* **ความละเอียด (Resolution):** ความสามารถในการแยกความแตกต่างของค่าที่วัดได้
* **ความแม่นยำ (Accuracy):** ความใกล้เคียงของค่าที่วัดกับค่าจริง
* **ความไว (Sensitivity):** อัตราการตอบสนองต่อการเปลี่ยนแปลงของสิ่งเร้า
* **เวลาในการตอบสนอง (Response Time):** เวลาที่เซ็นเซอร์ต้องใช้ในการตอบสนองต่อสัญญาณใหม่

## 2. ข้อมูลเซ็นเซอร์ KY-032 (Datasheet Overview)

โมดูล KY-032 เป็นเซ็นเซอร์ตรวจจับสิ่งกีดขวางระยะสั้นโดยใช้แสงอินฟราเรด (IR) ประกอบด้วยหลอดส่งอินฟราเรด (IR LED) และตัวรับอินฟราเรด (IR Receiver Photo Diode) โดยใช้ IC LM393 ในการเปรียบเทียบสัญญาณ นิยมนำไปใช้ในหุ่นยนต์เดินตามเส้น หุ่นยนต์หลบสิ่งกีดขวาง หรือระบบนับจำนวนชิ้นงาน

### หลักการทำงานของ KY-032

1. ตัวส่ง (IR LED) ปล่อยแสงอินฟราเรดออกไปด้านหน้า
2. เมื่อมีวัตถุเข้ามาอยู่ในระยะ แสงอินฟราเรดจะสะท้อนกลับมายังตัวรับ (IR Receiver)
3. สัญญาณที่รับได้จะถูกเปรียบเทียบโดย IC LM393
4. เมื่อตรวจพบแสงสะท้อนเกินเกณฑ์ที่ตั้งไว้ สัญญาณเอาต์พุต (OUT) จะเปลี่ยนเป็น **LOW** (0) และไฟ LED แสดงผลบนโมดูลจะติดสว่าง

### คุณสมบัติสำคัญของ KY-032

* **แหล่งจ่ายไฟ:** 3.3V ถึง 5V DC
* **เอาต์พุต:** Digital Output (OUT) ให้สัญญาณ HIGH (ไม่พบวัตถุ) / LOW (พบวัตถุ)
* **ตัวเปรียบเทียบสัญญาณ:** LM393
* **ระยะตรวจจับ:** ปรับได้ตั้งแต่ประมาณ 2 ซม. ถึง 40 ซม. (ขึ้นอยู่กับสีและพื้นผิวของวัตถุ)
* **ปรับความไวได้:** มี Potentiometer 2 ตัว (ปรับระยะตรวจจับ และปรับความถี่คลื่นอินฟราเรด)
* **มี Jumper เปิด/ปิดการทำงาน:** สามารถเปิด/ปิดการส่งสัญญาณ IR ได้ตามต้องการ

### ขาต่อและฟังก์ชัน

| Pin | ชื่อ | คำอธิบาย |
| --- | --- | --- |
| 1 | GND | ขาเชื่อมกราวด์ (0V) |
| 2 | +5V / VCC | จ่ายไฟ 3.3V - 5V |
| 3 | OUT | เอาต์พุตดิจิทัล (ปกติ HIGH / ตรวจพบวัตถุเป็น LOW) |
| 4 | EN | ขา Enable (ต่อ HIGH เพื่อเปิดใช้ / ต่อ LOW เพื่อปิดใช้งาน) |

### ข้อมูลทางเทคนิคทั่วไป

* **แรงดันจ่ายไฟ:** 3.3V ถึง 5V
* **กระแสไฟฟ้าที่ใช้:** $\approx 20\text{ mA}$
* **อุณหภูมิการทำงาน:** -10°C ถึง +50°C
* **มุมในการตรวจจับ:** ประมาณ 35 องศา
* **ระยะตรวจจับ:** 2 ถึง 40 เซนติเมตร
* **การปรับแต่ง:**
* R6 (Potentiometer 1): ปรับความถี่อินฟราเรด (ควรตั้งไว้ที่ค่าโรงงาน 38kHz)
* R5 (Potentiometer 2): ปรับระยะทางในการตรวจจับวัตถุ



## 3. การต่อวงจรกับ Arduino

| Arduino | KY-032 |
| --- | --- |
| 5V | +5V (VCC) |
| GND | GND |
| D2 | OUT |
| *(ไม่จำเป็นต้องต่อ)* | EN |

*หมายเหตุ: ขา EN หากไม่ต่อ โมดูลจะเปิดทำงานตลอดเวลาโดยอัตโนมัติผ่าน Pull-up resistor บนบอร์ด*

## 4. ตัวอย่างโค้ด Arduino

```cpp
const int obstaclePin = 2; // ขาเชื่อมต่อสัญญาณ OUT ของ KY-032
const int ledPin = 13;     // LED บนบอร์ด Arduino

void setup() {
  pinMode(obstaclePin, INPUT);
  pinMode(ledPin, OUTPUT);
  Serial.begin(9600);
}

void loop() {
  int obstacleState = digitalRead(obstaclePin);

  // เมื่อพบวัตถุ โมดูลจะส่งสัญญาณ LOW (0)
  if (obstacleState == LOW) {
    digitalWrite(ledPin, HIGH); // เปิด LED
    Serial.println("Status: Obstacle Detected!");
  } else {
    digitalWrite(ledPin, LOW);  // ปิด LED
    Serial.println("Status: Clear");
  }

  delay(100);
}

```

## 5. ข้อสังเกตและคำแนะนำสำหรับการใช้งาน

* **ผลกระทบจากแสงแวดล้อม:** แม้ว่าโมดูลจะมีการใช้วงจรกรองสัญญาณ แต่แสงแดดจัดหรือแสงอินฟราเรดจากแหล่งอื่นอาจรบกวนการทำงานได้
* **สีและพื้นผิวของวัตถุ:** วัตถุสีขาวหรือผิวเรียบจะสะท้อนแสงอินฟราเรดได้ดีกว่าวัตถุสีดำหรือผิวขรุขระ ทำให้ระยะการตรวจจับวัตถุสีดำสั้นกว่าวัตถุสีขาว
* **การปรับหมุน Potentiometer:** หากหมุนปรับ R6 (ความถี่) ผิดพลาด อาจทำให้เซ็นเซอร์ไม่ตอบสนอง ให้ปรับหมุนกลับมาจุดที่หลอดส่งและรับทำงานสอดคล้องกันที่ 38kHz
* **เหมาะสำหรับงานหลบสิ่งกีดขวางแบบสวิตช์:** KY-032 ให้เอาต์พุตแบบดิจิทัล (เจอ / ไม่เจอ) จึงไม่เหมาะสำหรับการวัดระยะทางเชิงตัวเลขที่แม่นยำ (เช่น หน่วยเซนติเมตร) หากต้องการวัดระยะทางแนะนำให้ใช้เซ็นเซอร์อัลตราโซนิก (เช่น HC-SR04)

## 6. สรุป

KY-032 เป็นโมดูลเซ็นเซอร์ตรวจจับสิ่งกีดขวางที่ใช้งานง่าย ประหยัด และตอบสนองได้รวดเร็ว เหมาะอย่างยิ่งสำหรับโปรเจกต์หุ่นยนต์หลบสิ่งกีดขวาง การตรวจจับวัตถุผ่านบนสายพาน หรือระบบนับจำนวนเบื้องต้นผ่านสัญญาณดิจิทัล High/Low
